GUIとShellは同じProject / Flow / MOD / Artifactを操作します。GUIはShellで行える操作を視覚化した操作パネルです。

機能ステータス:
- **Implemented** — 実装済み
- **Experimental** — 試験的
- **Planned** — 予定・未実装
- **Community** — Community MODで提供
